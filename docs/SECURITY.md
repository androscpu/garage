## Security, AuthN/Z, and Compliance

### Identity & Access
- OIDC provider (Keycloak/ORY) with SSO
- RBAC: org-level, property-level roles and fine-grained permissions
- SCIM user provisioning (future)

### Data Protection
- TLS everywhere, HSTS, secure cookies
- PII encryption at rest (column-level) and secrets management (KMS)
- PCI DSS SAQ A scope via hosted payment fields

### Audit & Compliance
- Audit logs for data access and configuration changes
- Metadata tagging for data residency and deletion workflows
