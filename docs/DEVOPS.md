## DevOps, Environments, and Observability

### Environments
- dev, staging, production with seeded demo data in dev

### CI/CD
- Build, test, lint on PR; image builds; helm deploys
- DB migrations via Prisma/Flyway

### IaC & Platform
- Terraform modules for VPC, DB, cache, cluster, secrets
- Kubernetes with Helm, cert-manager, external-dns, ingress

### Observability
- Metrics: Prometheus + Grafana
- Logs: Loki/ELK, structured JSON logs
- Tracing: OpenTelemetry + Tempo/Jaeger
